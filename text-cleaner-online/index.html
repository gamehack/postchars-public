Remove blank lines from copied text

Choose Remove empty lines when text contains blank lines from PDF exports, spreadsheets or notes. Collapse excess blank lines keeps paragraph separation while removing extra vertical space.

Remove HTML tags

Strip basic HTML markup removes simple tags and script/style blocks, adds line breaks around common block elements, and decodes a few common entities. This is a plain text convenience tool, not a full HTML parser or security sanitizer. For complicated HTML documents use a real HTML parser.

When should I use each operation?

Use repeated-space cleanup for text pasted from forms, tabs-to-spaces for tabular text you want to align manually, and basic HTML stripping for readable excerpts. Operations generate a preview so you can inspect any change before copying.

What each cleanup operation does

OperationEffectTypical use
Remove empty linesDeletes every line that is blank or contains only spacesLists and data where blank lines have no meaning
Collapse excess blank linesReduces three or more consecutive line breaks to a single blank lineDocuments where paragraphs should stay separate
Collapse repeated spacesTurns runs of spaces or tabs into one space and removes spaces at line endsText copied from PDFs or aligned with spaces
Convert tabs to four spacesReplaces each tab character with four spacesCode snippets and plain-text tables
Strip basic HTML markupRemoves script and style blocks and tags, turns block tags such as paragraphs and list items into line breaksText copied from page source or an email template

How to clean text step by step

  1. Paste the messy text into the input box.
  2. Choose one operation and review the cleaned result.
  3. Select Use result as input to apply another operation on top, for example strip HTML first, then collapse blank lines.
  4. Copy the final result.

Example

Input: <p>Opening hours:</p><ul><li>Mon–Fri 9–5</li><li>Sat 10–2</li></ul>. After Strip basic HTML markup and Collapse excess blank lines, you get three readable lines: “Opening hours:”, “Mon–Fri 9–5” and “Sat 10–2”.

What this tool does not do

The HTML stripper is designed for simple markup. It is not an HTML sanitizer, so do not use its output as a security filter for untrusted content you will display on a website; use a dedicated sanitization library for that. It also does not decode every HTML entity or fix broken markup. For hidden characters such as zero-width or non-breaking spaces, use the Unicode inspector; to join broken lines into paragraphs, use remove line breaks; and for targeted replacements, find and replace.
