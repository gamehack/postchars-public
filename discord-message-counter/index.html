FAQ

Does PostChars publish this text?

No. This tool calculates locally and lets you copy the draft to your platform.

Do emoji count as one?

Not always. Below you can compare visible graphemes, code points and UTF-16 units, which may differ for complex emoji.

Can I trust the displayed remaining count?

The count follows the documented rule or clearly labelled reference scope. The platform editor remains the final validator.
