Discord's 2,000 and 4,000 character limits

Discord's Help Center states that standard messages can contain up to 2,000 characters, and that Nitro subscribers can send messages up to 4,000 characters. This counter checks against 2,000 by default, using UTF-16 code units as a planning approximation. For plain text, UTF-16 units and visible characters are the same; for emoji they differ, because most emoji use two UTF-16 units and some sequences use more. Custom server emoji are sent as text codes such as <:name:123456789012345678>, which are much longer than the picture you see, so a message full of custom emoji can reach the limit sooner than expected.

How to use the Discord message counter

  1. Paste the message, including Markdown such as **bold**, code fences and links. Formatting symbols count as characters.
  2. Check the UTF-16 count against 2,000, or compare with 4,000 if you and the channel use Nitro limits.
  3. If a long announcement does not fit, split it at a heading or paragraph rather than mid-sentence.
  4. Copy the text into Discord. The Discord client is the final validator.

Writing longer Discord posts

Server announcements, patch notes and event details often run long. A few habits keep them readable:

  • Put the key fact in the first line: the date, the change or the action people need to take.
  • Use Discord Markdown sparingly: headings (#, ##), bullet lists and code blocks help, but each symbol counts toward the limit.
  • Move reference material to a thread or a pinned message rather than one oversized post.
  • Avoid mass mentions unless your server rules allow them; they notify everyone.

For bot developers: Discord's API applies its own field limits, such as for embeds, which are separate from message content. Check the developer documentation for the field you are filling.
