How to sort text alphabetically

Paste one value per line and choose A–Z or Z–A. Sorting uses a natural-number-aware English locale comparison, so Item 2 sorts before Item 10. Choose Original order when you only want deduplication.

Remove duplicates without losing your original data

The tool can remove repeated lines ignoring letter case, trim leading and trailing spaces, and remove empty lines. If keeping capitalization distinctions matters, enable Case-sensitive duplicates. The output is a separate preview until you explicitly copy or apply it.

Common questions

Can I shuffle a list?

Yes. Select Shuffle. Each operation may produce a different random order.

Does it upload my list?

No. Sorting and duplicate detection run locally in your browser.

How sorting works here

The sorter compares lines using your browser's language-aware comparison with natural number ordering, so item2 comes before item10 instead of after it, as it would in a plain character-by-character sort. When case sensitivity is off, “apple” and “Apple” are treated as equal for sorting and deduplication, and the first occurrence is kept. Lines that compare equal keep their original relative order.

Step by step

  1. Paste your list with one item per line. Lines are split on any line ending, including Windows CR LF.
  2. Choose an order: A–Z, Z–A, keep the original order, or shuffle randomly.
  3. Choose whether to trim spaces, remove blank lines, remove duplicates and match case.
  4. Select Process list, review the input, result and removed line counts, then copy the result or reuse it as new input.

Practical uses

  • Cleaning exported data: remove repeated email addresses, SKUs or tags before importing them elsewhere.
  • Keyword and hashtag lists: deduplicate and alphabetize so gaps and near-duplicates are easy to spot.
  • Bibliographies and glossaries: put entries in order before final formatting.
  • Random order: shuffle names for a draw or presentation order. The shuffle uses the browser's standard random generator and is fine for everyday use, not for anything that must be provably fair.

Things to watch: leading spaces can change the order if trimming is off; accented letters are sorted according to English rules; and very similar entries such as “colour” and “color” are not treated as duplicates.
