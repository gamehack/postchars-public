How to sort text alphabetically

Paste one value per line and choose A–Z or Z–A. Sorting uses a natural-number-aware English locale comparison, so Item 2 sorts before Item 10. Choose Original order when you only want deduplication.

Remove duplicates without losing your original data

The tool can remove repeated lines ignoring letter case, trim leading and trailing spaces, and remove empty lines. If keeping capitalization distinctions matters, enable Case-sensitive duplicates. The output is a separate preview until you explicitly copy or apply it.

Common questions

Can I shuffle a list?

Yes. Select Shuffle. Each operation may produce a different random order.

Does it upload my list?

No. Sorting and duplicate detection run locally in your browser.
