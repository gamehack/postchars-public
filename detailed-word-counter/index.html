Word count versus unique word count

Word count includes repeated terms, while unique word count counts distinct case-insensitive tokens. The tokenizer recognizes letters and numbers from multiple writing systems, but East Asian languages without spaces may require more advanced segmentation.

How is speaking time estimated?

This tool uses an adjustable concept rather than a promise: 130 words per minute is the fixed reference rate for this estimator. Real speech varies with audience, pauses, language, and presentation style. The existing Word Counter uses 225 words per minute for silent reading.

Why count UTF-8 bytes?

Some software interfaces and data fields have byte-based limits. Emoji and accented characters may use more than one byte even when displayed as a single symbol. For grapheme and code point differences, see the Unicode Inspector.

Using vocabulary statistics to edit

The ratio of unique words to total words is a rough measure of lexical variety. In a 500-word draft, 250 unique words is typical of conversational writing; a much lower ratio may point to repetition worth reviewing. Do not chase a target: technical writing legitimately repeats precise terms, and short texts naturally have high ratios. Use the keyword density checker to see which words and phrases repeat most.

Average word length is another quick signal. Plain English prose usually averages a little under five letters per word; a draft averaging six or more is likely to read as dense, which the readability checker can confirm.

When bytes matter

Many systems limit storage size rather than characters: database columns, SMS gateways, push notification payloads, some APIs, and Bluesky's 3,000-byte post limit. English text uses one byte per character in UTF-8, but accented letters typically use two, most Chinese, Japanese and Korean characters three, and emoji four or more. A 1,000-character Japanese paragraph is roughly 3,000 bytes.

Step by step

  1. Paste or type the text.
  2. Read the core counts first: words, lines and bytes.
  3. Use speaking time when preparing a talk, video script or podcast intro; 130 words per minute is a measured, conversational pace.
  4. Copy the text when finished. Nothing is uploaded.
