How TikTok caption length is measured

TikTok's Content Posting API reference documents a maximum of 2,200 for the video caption field, measured in UTF-16 code units. That unit matters. Plain English letters, digits and spaces use one unit each, but most emoji use two, and some combined emoji use far more: a family emoji built from three people and two zero-width joiners is eight UTF-16 units even though it appears as one symbol. This counter therefore shows three numbers side by side: the UTF-16 count that the API limit applies to, visible graphemes (what you see) and Unicode code points.

How to use the TikTok caption counter

  1. Paste your caption, including hashtags, @mentions and any disclosure text such as a paid-partnership note.
  2. Read the Selected counting units figure, which uses UTF-16 for TikTok, and the remaining amount against 2,200.
  3. If you are close to the limit, check the emoji first: removing one emoji frees two or more units.
  4. Copy the caption, or download it as a plain-text file, and paste it into TikTok or your scheduling tool.

Writing a caption that adds to the video

Most people watch before they read, so the caption's job is to add what the video cannot: context, a key fact, the recipe quantities, the product name or a question that invites comments. Keep the most useful sentence first, because the caption is collapsed in the feed. Use a handful of specific hashtags that describe the video rather than a long block of popular tags; they take up the same space as words. If you publish through a third-party scheduler, remember that it may use the API rule while the app's own editor applies its own validation, so leave a small margin and confirm in TikTok.
