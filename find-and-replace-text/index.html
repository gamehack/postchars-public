Find uses literal text, not a regular expression. Replacement symbols like $& stay literal. The source is unchanged until you select Use result as input.

How to replace a word or phrase in a document

  1. Paste the text you want to edit into the Text to edit field.
  2. Enter the exact word or phrase you want to find.
  3. Type the replacement, or leave Replace with empty to delete matches.
  4. Choose Match case or Whole words only if needed.
  5. Select Replace first or Replace all; review the result, then copy it.

Case-sensitive versus case-insensitive matching

Without Match case, searching for color can match Color and COLOR. With Match case, only matching capitalization is replaced. The replacement text is inserted exactly as typed; it does not automatically imitate the original capitalization.

Whole-word matching protects longer words

Replacing cat inside concatenate can damage a document. Enable Whole words only to restrict matches to boundaries around letters, numbers and underscores. For example, matching cat as a whole word will not change cats. For languages without spaces between words, inspect the preview carefully.

Why use a literal text replacer?

Literal matching avoids regular-expression characters being interpreted as commands. If your search includes a period, bracket or dollar sign, the tool looks for those actual characters. This makes it useful for quick edits to product names, URLs, marketing copy and repeated phrases without needing to learn regex syntax.

Frequently asked questions

Can I delete all occurrences of a term?

Yes. Leave the replacement field empty and select Replace all to generate a preview without the matched text.

Does Replace all modify my original textarea?

No. The edited text appears in a separate read-only result box until you explicitly choose Use result as input.

Is this a regex editor?

No. It deliberately uses literal search terms. For complex expressions, use a regular expression editor with its own preview and validation.
