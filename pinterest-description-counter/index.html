What the 500 reference covers

Pinterest's developer documentation for the Save button states that the prefilled description set with data-pin-description can be up to 500 characters. That is the field this counter checks, in Unicode code points. It is a well-documented reference, but it is specific to that website feature: Pinterest's own Pin builder, its API and its ads tools may present or validate descriptions differently, and the amount of text shown on a Pin in the feed is far shorter than 500. Use this counter to keep descriptions tidy and complete, and confirm the final text in Pinterest.

How to use the Pinterest description counter

  1. Paste the description you plan to use, whether for a Save button on your site or a Pin you create manually.
  2. Check the code point count against the 500 reference.
  3. Read the first sentence on its own; it is the part most likely to be shown.
  4. Copy the description, or download it as a plain-text file for your site templates.

Writing descriptions that help people find and use a Pin

Pinterest works like a visual search engine: people search for ideas, recipes, outfits and projects, then save what they want to try. A good description says plainly what the Pin shows and why it is useful, using the words someone would search for. For example, “One-pan lemon garlic chicken with potatoes, ready in 40 minutes. Simple weeknight dinner for four with pantry ingredients.” describes the dish, the time and the audience in 122 characters.

  • Describe, don't stuff. A natural sentence with relevant terms beats a list of keywords.
  • Match the destination. The description should reflect the page the Pin links to.
  • Add specifics such as size, time, difficulty or materials that help someone decide to save it.
