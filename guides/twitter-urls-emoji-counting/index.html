The difference between visible and weighted characters

A visible character is what your eyes perceive as a single unit, such as a letter or emoji. But computers can represent one visual symbol with several code points. X's published text rules also assign different weights to some characters. This is why plain JavaScript string length, a word processor's count and a social platform's count can disagree.

Why do links count as 23 characters?

Under the published twitter-text v3 rules, a recognized URL has a configured fixed weight of 23 characters. For typical recognized links, the source URL's visible length therefore does not determine the number of characters left in a post. For example, a short https://example.com and a considerably longer path on that same domain can each count as 23 characters.

The distinction matters when you add a link to a nearly finished draft: manually subtracting the URL's ordinary string length can produce the wrong result. Some unusual or malformed links may not be recognized by the parser, so use the actual text you intend to publish.

How are Chinese, Japanese and Korean counted?

In twitter-text v3, many characters used in Chinese, Japanese and Korean are weighted at two rather than one. For example, the string 中文 has two visible characters but a weighted length of four under these rules. Combining CJK and Latin characters in one post can therefore make mental estimates unreliable.

How much does an emoji count?

Many emoji count as two weighted characters. A simple 😀 may look like one visible symbol but uses two weighted units. Sequences involving skin-tone modifiers, joiners or flags can consist of several Unicode code points. Their treatment depends on the text parser and may differ from the count in a plain character counter. Frequently asked questions

Do spaces count on X?

Yes. Ordinary spaces and punctuation contribute to the weighted total.

Does shortening a URL save characters?

Under the published URL-weighting rules, typically not: a recognized link uses the same configured weight. A short-link service may help readability or tracking, but should not be assumed to reduce the X character count.

Should I trust a screenshot-based post preview?

Only as a visual guide. The actual post display depends on X's current UI and may be different. Always verify in X before publishing.
