Writing and Character Limit Guides

Character limits are only half of publishing well. These guides explain how each platform actually measures text, where the numbers come from, and how to write openings, headlines, threads and descriptions that work within them.

Every guide cites the platform’s own documentation where one exists and says plainly when a figure is only a planning reference. We review guides when platforms change their rules; each page shows when it was last checked. Read more about how PostChars researches and maintains its content.
