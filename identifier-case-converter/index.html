Identifier Case Converter

Convert words and variable names into camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE or Title Case.

Your entered text is processed locally. No account, upload or paid AI service is required. Always verify final platform formatting.

Convert identifier naming conventions

camelCase starts with lowercase, PascalCase capitalizes each word, snake_case separates with underscores, and kebab-case uses hyphens. CONSTANT_CASE uses uppercase letters and underscores.

What happens to acronyms?

The tool detects common boundaries such as HTTPResponse and first_name before converting. This simple tokenizer may not perfectly infer unusual acronyms or language-specific punctuation; inspect results before using them in source code.

Keep names consistent

Consistent naming makes configuration, CSS classes, API fields and source code easier to maintain. Paste an identifier and select a naming style for a local preview.
