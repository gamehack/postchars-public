How to read these results

For a field-by-field explanation of all 12 checks, including which limits are official, API-specific or planning references, read the Social Media Character Limits: 12 Platforms Compared guide.

The checker uses X's published weighted-count algorithm, Bluesky's documented grapheme and UTF-8 limits, and explicitly scoped rules for several API fields. Other platform limits are labelled planning references and may not match the current publisher app. Facebook has no verified universal hard limit. Reddit title and Pinterest prefilled descriptions are scoped references. An in-limit result is not a guarantee that a platform will accept the post.

Which platform counter should you use?

For standard X posts, the X character counter explains weighted links and emoji. Instagram caption counting and LinkedIn post counting provide focused drafting workspaces. TikTok, Bluesky, Discord, and Telegram Bot API have dedicated checks with source-specific notes. Google Ads uses different asset rules and is intentionally not treated as a social post.

FAQ

Is the same text valid everywhere?

No. Fields, media types, paid plans, app versions, and platform validation methods vary. Use each destination publisher as the final validator.

Is my text uploaded?

No. Calculations and copy actions are performed locally. Optional analytics measure anonymous actions only after consent, never your draft.

Why are counts different?

Visible graphemes, Unicode code points, UTF-16 units, UTF-8 bytes and X weighted characters are not interchangeable, especially for URLs and emoji.

How to use the checker step by step

  1. Paste the draft exactly as you intend to publish it, including links, mentions, hashtags and line breaks.
  2. Scan the platform cards. Each shows the field it checks, the counting unit, the limit or reference, and whether the draft fits.
  3. Open the plain-text excerpts to see roughly how the opening reads on X, Instagram and LinkedIn.
  4. Where a platform is over its limit, edit the draft or create a platform-specific version in its dedicated counter.
  5. Copy the final text into each platform, which remains the final validator.

Worked example

Take a 260-character announcement that includes one 60-character link and two emoji. On X, the link counts as 23 weighted characters and each emoji as 2, so the post measures about 225 and fits within 280. On Bluesky, the full link text and each emoji count as graphemes, so the same draft measures 260 graphemes, still under 300, but adding a 41st character beyond that would fail Bluesky before X. On Threads (500), LinkedIn (3,000) and Instagram (2,200) it fits comfortably, but the opening line is what each feed shows first. One draft, five different measurements, all correct for their platform.

Adapting one message for several networks

  • Keep the core sentence identical so the message is consistent.
  • Adjust the opening to each feed's preview: shorter for X and Bluesky, a stronger first line for LinkedIn and Instagram, where text is collapsed.
  • Move hashtags to where each platform's audience expects them, usually the end.
  • Check links: X weights them at 23, most other platforms count their full length.
