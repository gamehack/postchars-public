How to read these results

For a field-by-field explanation of all 12 checks, including which limits are official, API-specific or planning references, read the Social Media Character Limits: 12 Platforms Compared guide.

The checker uses X's published weighted-count algorithm, Bluesky's documented grapheme and UTF-8 limits, and explicitly scoped rules for several API fields. Other platform limits are labelled planning references and may not match the current publisher app. Facebook has no verified universal hard limit. Reddit title and Pinterest prefilled descriptions are scoped references. An in-limit result is not a guarantee that a platform will accept the post.

Which platform counter should you use?

For standard X posts, the X character counter explains weighted links and emoji. Instagram caption counting and LinkedIn post counting provide focused drafting workspaces. TikTok, Bluesky, Discord, and Telegram Bot API have dedicated checks with source-specific notes. Google Ads uses different asset rules and is intentionally not treated as a social post.

FAQ

Is the same text valid everywhere?

No. Fields, media types, paid plans, app versions, and platform validation methods vary. Use each destination publisher as the final validator.

Is my text uploaded?

No. Calculations and copy actions are performed locally. Optional analytics measure anonymous actions only after consent, never your draft.

Why are counts different?

Visible graphemes, Unicode code points, UTF-16 units, UTF-8 bytes and X weighted characters are not interchangeable, especially for URLs and emoji.
