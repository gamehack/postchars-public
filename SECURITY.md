# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository. Include:
- affected version or commit,
- steps to reproduce,
- impact and any relevant proof of concept.

Do not include real user text, credentials, tokens, or personal data in reports.

## Scope
The application is designed to process entered text locally in the browser. Security reports involving unintended transmission or disclosure of entered text are in scope.
