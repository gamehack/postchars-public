How an X thread splitter works

Paste your draft and the tool splits text at word boundaries where possible. Each part is numbered (1/N), (2/N), and so on, and the numbering itself counts against X's 280 weighted characters.

URLs and emoji use X weighting

The tool uses the open-source twitter-text library, which counts recognized URLs as a fixed weight and some Unicode characters differently from their visual length. X may change rules or offer subscriber post formats; confirm each draft in X before publishing.

What to check before posting

Review the boundaries for coherent paragraphs, keep links intact, and ensure the final post has a clear conclusion. This is a copy-and-paste tool, not an automatic publisher.

How the splitter decides where to break

The splitter works in three steps. First, it checks whether your whole draft fits in one standard post of 280 weighted characters; if it does, it returns a single post without numbering. Otherwise, it estimates how many posts are needed and reserves space for a suffix such as (3/8) on every post. Finally, it fills each post word by word until the next word would exceed the budget, so words are not cut in half. Links are kept intact and count as 23 weighted characters each, as in X's twitter-text rules. If the number of posts changes once the suffix is included, the splitter recalculates until the numbering is stable.

How to use the X thread splitter

  1. Write or paste the full draft. Separate ideas into paragraphs; it makes the breaks easier to review.
  2. Read the numbered result. Each post shows the text that will be published with its suffix.
  3. Edit the source where a break falls awkwardly, such as between a number and its unit, then check again.
  4. Copy the result or download it, then paste each post into X's thread composer.

Automatic splitting is a first draft

An algorithm can guarantee that every post fits; it cannot guarantee that every post makes sense on its own. After splitting, read each post in isolation. Move a sentence into the next post if a break separates a claim from its evidence, and make sure the first post states the topic and the payoff. If the thread is long, consider whether a short summary post with a link would serve readers better. Our guide to structuring an X thread covers openings, pacing and link placement with an example, and the X counting guide explains weighted characters.

The splitter does not publish anything and does not connect to your X account. Drafts up to 20,000 UTF-16 units are processed locally in your browser.
