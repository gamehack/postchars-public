How long can a YouTube description be?

YouTube Help documents a 5,000-character limit for video descriptions. Check the actual YouTube Studio editor before publishing, particularly for unusual Unicode or formatting.

What belongs in a video description?

Use the opening lines for a precise explanation of the video. Add relevant source links, chapters, corrections and disclosures as needed. Avoid misleading keyword repetition.

Why check the full description?

URL links, timestamps and line breaks all occupy text positions. This counter helps you edit before switching back to Studio, but it is not an upload or publishing integration.

Measuring a YouTube description correctly

This counter checks visible characters against the 5,000-character reference. YouTube Studio shows its own counter for the description field and is the final authority. If you upload through the YouTube Data API or a scheduling tool, note that the API reference describes the description limit as 5,000 bytes and disallows the < and > characters. For English text, bytes and characters are the same; for accented, non-Latin or emoji-heavy text, the byte count is higher. The UTF-16 figure shown here helps you spot emoji that use extra storage.

A description structure that works

  1. Summary first. Only the first lines show before viewers expand the description, so start with one or two sentences that say what the video covers.
  2. Labelled links. Resources mentioned in the video, each with a short description of where it goes.
  3. Chapters. Timestamps starting at 00:00, at least three in ascending order, each section at least 10 seconds long, per YouTube Help.
  4. Context. Corrections, credits, equipment, sources.
  5. Disclosures. Sponsorships and affiliate links, stated plainly.
  6. A few hashtags at the end, if relevant. YouTube may show up to three near the title and ignores all hashtags on a video that has more than 60.

Example opening

“Learn how to replace a bike chain at home with basic tools. We cover sizing the new chain, using a chain tool, and the two mistakes that cause skipping.” That is 152 characters: specific, searchable and useful even if nobody expands the rest.

Common mistakes

  • Opening with a list of links or social handles instead of a summary.
  • Pasting a block of keywords; YouTube's policies prohibit repetitive tags and keyword lists in descriptions.
  • Using angle brackets, which the field does not accept.
  • Letting boilerplate push the video-specific information below the fold.
