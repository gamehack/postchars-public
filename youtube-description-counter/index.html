How long can a YouTube description be?

YouTube Help documents a 5,000-character limit for video descriptions. Check the actual YouTube Studio editor before publishing, particularly for unusual Unicode or formatting.

What belongs in a video description?

Use the opening lines for a precise explanation of the video. Add relevant source links, chapters, corrections and disclosures as needed. Avoid misleading keyword repetition.

Why check the full description?

URL links, timestamps and line breaks all occupy text positions. This counter helps you edit before switching back to Studio, but it is not an upload or publishing integration.
