What the 4,096 limit applies to

The Telegram Bot API documents that the text parameter of sendMessage may contain 1–4,096 characters after entities parsing. That phrase is important for bot developers. If you send a message with parse_mode set to HTML or MarkdownV2, the tags and markup symbols are removed and turned into formatting entities before the length is checked. So <b>Order shipped</b> counts as the 13 characters of “Order shipped”, not the 20 characters you typed. This counter measures the text you paste in Unicode code points, so paste the visible text, not the raw markup, for the closest estimate.

How to use the Telegram bot message counter

  1. Paste the message text as the user will see it.
  2. Check the code point count against 4,096.
  3. If your template includes variables such as names or order lists, test with the longest realistic values.
  4. For messages that may exceed the limit, split them in your bot code at paragraph boundaries and send several messages.

Practical tips for bot messages

Long bot replies are hard to read on a phone. Put the answer or status in the first line, use short paragraphs, and move detail behind an inline button or a link. When you escape text for MarkdownV2, remember that many punctuation characters must be escaped with a backslash; those backslashes are removed during parsing but make the raw string longer, which is another reason to measure the displayed text. Messages for ordinary Telegram chats typed in the app are not covered by this Bot API rule. Related: the Discord message counter, the SMS segment counter and our guide to SMS encoding.
